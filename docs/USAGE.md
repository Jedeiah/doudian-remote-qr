# 使用手册（从 0 到 1）

## 角色

| 角色 | 用什么 | 账号 |
| --- | --- | --- |
| 超级管理员 | 浏览器 `/admin` | admin |
| 坐席 | Windows 坐席端 | seat（所有坐席共用） |
| 扫码人 | 浏览器 `/scan` | scanner（所有扫码人共用） |

## 一、管理员首次配置

1. 服务端首次启动后，控制台会打印 `admin / seat / scanner` 三个初始密码。
2. 打开 `https://域名/admin`，用 admin 登录。
3. 在「账号管理」里修改 seat 和 scanner 的密码（改完所有已登录端会掉线）。
4. 把 seat 密码发给每个坐席；把 scanner 密码发给扫码人。

## 二、坐席端安装

1. 直接使用打包好的 `DoudianRemoteQR.exe`（Rust 单文件，目标电脑不需要安装 Python 或任何运行时）。
2. 双击 exe：程序常驻系统托盘，不弹终端窗口；图标可能在任务栏 `^` 溢出区。
3. 双击托盘图标（或右键→打开面板）打开 `http://127.0.0.1:8765/`。
4. 面板登录 seat 账号后，在功能页输入店铺名并发起登录；一次登录可多次发起不同店铺。
4. 第一次登录会绑定「坐席03」这个名称到本机；换机器需要用管理员在 /admin 删除旧坐席绑定。
5. 打开抖店客户端，**退出登录，停在扫码登录页**，窗口不要最小化。

## 三、扫码人使用

1. 用电脑浏览器打开 `https://域名/scan`，用 scanner 登录。
2. 坐席发起登录后，待扫码列表自动出现。
3. 点击这条会话，网页显示实时二维码。
4. 用**手机上的抖店 App**扫码（不是用打开网页的那台设备扫）。
5. 手机确认登录后，在网页点「我已扫码」。
6. 坐席确认成功后，该条自动从列表消失。

> 只有手机时：网页点「保存二维码」保存到相册，再用抖店 App 的相册识别。同一部手机不能既显示二维码又扫码。

## 四、坐席端操作

| 按钮 | 何时可用 | 作用 |
| --- | --- | --- |
| 确认登录成功 | VALID / SCANNED | 结束本单 |
| 取消会话 | 所有非终态 | 关闭会话，扫码端列表移除 |

二维码过期会自动刷新，扫码人不需要操作。

## 五、二维码过期

二维码过期完全由坐席端自动处理：

1. 坐席端通过二维码特征（过期后出现的蓝色刷新按钮）判断过期
2. 自动点击刷新按钮，扫码端显示"自动刷新中"
3. 新码出现后自动恢复"有效"

扫码端没有手动刷新按钮；自动刷新连续失败时会话自动结束并提示，坐席可取消/重新发起。

## 六、常见问题

| 问题 | 处理 |
| --- | --- |
| 扫码端列表一直空 | 确认坐席已点「发起登录」；确认坐席在线 |
| 二维码一直不出现 | 确认抖店客户端停在扫码登录页、窗口未最小化 |
| 提示「该坐席名称已被其他设备占用」 | 管理员在 /admin 删除旧坐席绑定，或换一个坐席名称 |
| 提示「该店铺已有进行中的会话」 | 先完成/取消原来那条会话 |
| 登录过期 | 重新登录即可（登录会话默认 12 小时） |
